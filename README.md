# Heimstart Pflichtseiten

Statische Seiten für die Heimstart-App (Android und iOS): Datenschutz, Support, Kontolöschung, Impressum.
Ausgeliefert über GitHub Pages, Zieladresse https://heimstart.de/.

Die neue Domain ist bestellt, ihre DNS- und TLS-Aktivierung stehen noch aus.
Bis der neue Mailweg verifiziert ist, bleibt support@move-master.de die
erreichbare Kontaktadresse. Kein zusätzliches Hosting- oder Workspace-Abo.

Die bisherige Website im Repository Daeniaell/movemaster-site bleibt für
installierte Appversionen unter move-master.de erreichbar. Medien bleiben
unverändert; der gesonderte neue Markenschriftzug ist nicht Teil dieser Runde.

Keine Skripte, keine Cookies, keine externen Schriftarten. Änderungen direkt in den HTML-Dateien vornehmen.
